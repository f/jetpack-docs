Use the product's **Troubleshoot and support** page to find its canonical support destination. In general:

- Use product support for configuration, connected-service, account, entitlement, and billing questions.
- Use public GitHub issues only for reproducible source-code defects that the repository accepts.
- Use WordPress.org support for public plugin-release questions when the product directs users there.
- Use a security reporting channel for vulnerabilities; do not publish exploit details in an ordinary issue.

Include the sanitized bundle from [Collect safe diagnostic information](safe-diagnostics.md). State the outcome you need and the checks already completed. Do not post the same request in several channels simultaneously; link existing reports when coordination is necessary.
