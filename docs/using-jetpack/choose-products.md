Choose by outcome and operational ownership. Pricing, entitlements, and availability can change, so confirm them through each product's canonical link in the [product catalog](/docs/products/).

| Outcome | Start with |
| --- | --- |
| A broad collection of connected site features | [Jetpack](/docs/products/jetpack/) |
| Spam protection | [Akismet](/docs/products/akismet/) |
| Restore or download a site backup | [VaultPress Backup](/docs/products/backup/) |
| Improve front-end performance | [Jetpack Boost](/docs/products/boost/) |
| Manage customer relationships | [Jetpack CRM](/docs/products/crm/) |
| Collect structured submissions | [Jetpack Forms](/docs/products/forms/) |
| Reduce malicious login traffic | [Jetpack Protect](/docs/products/protect/) |
| Investigate malware or site threats | [Jetpack Scan](/docs/products/scan/) |
| Replace or enhance site search | [Jetpack Search](/docs/products/search/) |
| Publish to social networks | [Jetpack Social](/docs/products/social/) |
| Understand site traffic | [Jetpack Stats](/docs/products/stats/) |
| Host and deliver video | [Jetpack VideoPress](/docs/products/videopress/) |
| Generate or revise editor content | [Jetpack AI Assistant](/docs/products/ai/) |

## Avoid accidental overlap

Inventory existing backup, cache, search, security, analytics, form, and social plugins. If two tools own the same outcome, decide which system is authoritative before activation. Test one change at a time and keep a rollback path.
