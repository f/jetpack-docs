Use these routes to avoid mixing setup instructions from different products.

- Secure logins: [Use and configure Protect](/docs/products/protect/use-and-configure/).
- Review a suspected threat: [Use and configure Scan](/docs/products/scan/use-and-configure/).
- Restore content or the site: [Use and configure Backup](/docs/products/backup/use-and-configure/).
- Improve performance: [Use and configure Boost](/docs/products/boost/use-and-configure/).
- Improve search results: [Use and configure Search](/docs/products/search/use-and-configure/).
- Review traffic: [Use and configure Stats](/docs/products/stats/use-and-configure/).
- Publish to social networks: [Use and configure Social](/docs/products/social/use-and-configure/).
- Create and manage forms: [Use and configure Forms](/docs/products/forms/use-and-configure/).
- Host a video: [Use and configure VideoPress](/docs/products/videopress/use-and-configure/).
- Work with editor AI: [Use and configure AI Assistant](/docs/products/ai/use-and-configure/).
- Control spam: [Use and configure Akismet](/docs/products/akismet/use-and-configure/).
- Manage contacts and sales workflows: [Use and configure CRM](/docs/products/crm/use-and-configure/).

For each task, record the starting state, make one scoped change, exercise representative test data, and confirm the result in both the product UI and the affected visitor-facing surface.
