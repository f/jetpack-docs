| How do I get account or site-specific help? | The support route linked from the owning product guide; do not post private diagnostics publicly |
| How do I report a security vulnerability? | [Automattic security guidance](https://automattic.com/security/) rather than a public issue |

Immutable links are preferred in reference pages because line-level claims remain auditable. Use current product support pages for procedures that change operationally, and label version-specific behavior when the installed release differs from this documentation's source revision.

Never include credentials, tokens, private site URLs, customer content, or full diagnostic archives in a public issue. Reduce a report to the minimum reproducible example and share sensitive details only through the official private support or security channel.
